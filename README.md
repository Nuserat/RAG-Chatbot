Academic RAG-Based Q&A Chatbot

A Retrieval-Augmented Generation (RAG) chatbot that answers Master's student questions by searching academic and educational PDF documents and generating evidence-based responses.

Overview

This project investigates document chunking as a database physical-design decision in RAG systems. 
Different chunking strategies are experimentally compared to identify the best balance between retrieval quality, answer quality, latency, and storage
